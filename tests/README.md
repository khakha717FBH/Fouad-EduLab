# مجموعة الاختبارات — مختبر فؤاد التعليمي

**التشغيل:** `npm install jsdom` مرّة واحدة، ثم من جذر المستودع:

```
node tests/all.js          # المجموعة كاملةً
node tests/lesson-05.test.js   # مجموعة واحدة
```

لا خادم ولا اتصال بالشبكة. الاختبارات تقرأ ملفات المستودع نفسها من
القرص — لا نسخًا منها ولا بدائل — فما ينجح هنا هو ما يعمل عند الطالب.

## المجموعات التسع

| الملف | ما يحميه |
|---|---|
| `quiz-engines.test.js` | محرّكات `window.Quiz` على صفحة فحص محايدة — **هذه هي التي تحمي الدروس القادمة** |
| `chips-multi.test.js` | محرّك الرقاقات: التصنيف متعدّد إلى واحد، التلميح عند الوضع الخاطئ، النقاط بالرقاقة، وانحدار الخانة القديمة الطراز |
| `lesson-03.test.js` | سلوك درس 03 كما يراه الطالب |
| `lesson-04.test.js` | سلوك درس 04 كما يراه الطالب |
| `geometry-l4.test.js` | فحص عددي لمسارح درس 04: الحدود، التلامس، الأعمدة، الزوايا |
| `lesson-05.test.js` | سلوك درس 05 كما يراه الطالب |
| `geometry-l5.test.js` | فحص عددي لمسارح درس 05: الحدود، إطار القطعة، التداخل، الأعمدة |
| `lesson-01.test.js` | انحدار: درس يربط `template.js` ولا يستعمل المحرّكات |
| `lesson-02.test.js` | حصانة: درس لا يربط المشترك أصلًا |

## ملفات مساعدة (لا تُشغَّل وحدها)

| الملف | الدور |
|---|---|
| `run.js` | عدّاء اختبار صغير بلا أي إطار خارجي: `describe / it / eq / ok / no / has` |
| `harness.js` | تحميل صفحة في jsdom مع بدائل المتصفّح، وأدوات نقر وكتابة واختيار |
| `fixtures/` | صفحات فحص محايدة للمحرّكات المشتركة |
| `flows-l3.js` · `flows-l4.js` · `flows-l5.js` | مسارات الطالب في كل درس، تُكتب مرّة وتُستعمل في كل اختبار |
| `snapshot-l4.js` · `snapshot-l5.js` | مولّدا صفحة اللقطات البصرية — **أداة فحص لا اختبار**، ولا يدخلان في `all.js` |

### خيارات `harness.loadLesson`

- `storage` — كائن تخزين قابل للنقل بين نسختَي jsdom، لمحاكاة إعادة تحميل الصفحة
- `hash` — مرساة، لمحاكاة الدخول من الخارج إلى محطة متقدّمة
- `reduceMotion` — مفعّل افتراضيًّا فتقصر المهل الزمنية

## قواعد الكتابة

- **الاختبار يُكتب على ما يفعله الطالب ويراه**، لا على البنية الداخلية.
  الاختبار الذي يعرف أسماء الدوالّ ينهار عند أول ترقية.
- **خطّ الأساس يُبنى قبل أي تعديل لا بعده.**
- **كل اختبار يُكتب يُرفَع إلى `tests/`** وإلا ضاع بانتهاء الجلسة.
- **الاختبار المنطقي لا يكشف ما لا يُقاس:** كل بناء بصري جديد يرافقه
  فحص عددي (`geometry-*`) **وفحص بالعين** عبر صفحة اللقطات. وما لا
  يغطّيه أي اختبار — الحركات والأصوات والإحساس البصري العام — يبقى
  للعين وحدها.
