# اختبارات مختبر فؤاد التعليمي

مجموعة اختبارات تفاعلية تعمل على **ملفات المستودع نفسها** — لا على نسخ منها.
تُشغَّل بـ Node وحده، بلا خادم ولا اتصال بالإنترنت.

## التشغيل

```bash
cd Fouad-EduLab
npm install jsdom      # مرّة واحدة فقط
node tests/all.js      # كل المجموعات
```

أو مجموعة واحدة:

```bash
node tests/lesson-03.test.js
node tests/quiz-engines.test.js
```

## المجموعات

| الملف | ماذا يحمي |
|---|---|
| `quiz-engines.test.js` | محرّكات `window.Quiz` المشتركة على صفحة فحص محايدة — **هذه هي التي تحمي الدروس القادمة** |
| `lesson-03.test.js` | سلوك درس 03 كما يراه الطالب |
| `lesson-01.test.js` | انحدار: درس يربط `template.js` ولا يستعمل المحرّكات |
| `lesson-02.test.js` | حصانة: درس لا يربط المشترك أصلًا |

## القاعدة الحاكمة لكتابة اختبار جديد

**اكتب ما يفعله الطالب ويراه، لا ما يفعله الكود.**

الاختبار الذي يعرف أسماء الدوالّ الداخلية أو سمات النطاق ينهار عند أول
ترقية فيصير عبئًا لا حماية. ولذلك تلتقط هذه المجموعات مجموعةَ الخيارات
عبر اسم حقل الراديو (`name`) لا عبر سمة النطاق — الاسم جزء من دلالة
النموذج ولا يتغيّر بترقية المحرّكات.

**ولا تُشغَّل الاختبارات على نسخة، بل على الملف الحيّ.** جهاز الاختبار
(`harness.js`) يقرأ ملف الدرس والملفات المشتركة من القرص ويدمجها بترتيب
وسومها نفسه، فينفَّذ الكود كما ينفَّذ في متصفّح الطالب.

## ما لا تغطّيه

المسارح البصرية (SVG) والحركات والأصوات تُفحص بالعين لا بالاختبار.
والاختبارات تفترض تفعيل «تقليل الحركة» كي تختصر مهل الطيّ.
